# Tæt på

Det nærmeste offentlige toilet, drikkevand, legeplads, bibliotek, badested, hundeområde,
genbrugsstation og elbil-lader i København. Én HTML-fil, ingen backend: siden henter
kommunens egne kortlag direkte fra `wfs-kbhkort.kk.dk` (Open Data DK), når den åbnes.

Bygget af en AI-agent som demo til Projektledelsesdagen 2026, Københavns Kommune.
